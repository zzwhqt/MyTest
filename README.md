# 轻刷题

<p align="center"><img src="Resources/AppIcon.png" alt="轻刷题 Logo" width="180"></p>

一款只依赖 macOS 原生 AppKit、PDFKit 和 Carbon 的离线悬浮刷题工具。应用分为可最小化的管理页和独立悬浮答题页。

应用图标使用圆角纯白底板，四个外角保持透明，在 Dock 中显示为圆润轮廓。

**[下载轻刷题 0.1.13 macOS DMG 安装包](Releases/轻刷题-0.1.13-macOS.dmg)**

## 安装

1. 下载并打开 DMG。
2. 将“轻刷题.app”拖入“Applications”文件夹。
3. 在“应用程序”中启动轻刷题。

当前安装包使用本地签名。如首次启动时 macOS 提示无法验证开发者，请在 Finder 中右键应用并选择“打开”。

## 构建

```bash
chmod +x build.sh
./build.sh
```

生成的应用位于 `dist/轻刷题.app`。双击即可启动；菜单栏会出现“题”图标。

## 生成 DMG 安装包

```bash
chmod +x package_dmg.sh
./package_dmg.sh
```

生成的 `dist/轻刷题-<版本>-macOS.dmg` 可直接打开，将“轻刷题.app”拖入“Applications”即可安装。

## 使用

- 导入时只需一个同时包含题目、答案和解析的合订 PDF，选择后点击“导入并识别”。
- 也可将这一个 PDF 直接拖入管理页的拖放区域，应用会自动识别并导入。
- “当前题库”下拉框可在内置题库和已导入题库之间切换，并记住下次启动时的选择。
- 题库使用稳定身份保存成绩和整卷断点，重复导入同一题库不会再让已有进度看起来消失；旧版本记录会自动兼容迁移。
- 管理页可逐题勾选，或用起止题号批量选择本次范围。
- 判题方式、随机、错题、锁定、移出隐藏、整卷时限、缩球暂停计时、背景透明度、统一文字颜色和答题字号全部在管理页设置。
- 点击“开始 / 更新答题页”后，管理页自动隐藏，只留下显示进度、题干、图片和选项的独立答题页。
- 答题页默认以 360×390 打开，可自由调整宽度和高度（最小 240×180）；题干、选项和解析只在当前宽度内自动换行，不会因内容变长而改变窗口宽度。点击右上角 `×` 会关闭答题页并回到管理页。
- 背景透明度可设为 0，且只影响背景；题目、图片、选项和结果文字始终不透明。
- 含图题可点击图片铺满答题页预览；左上角 `− / +` 按钮可直接缩放（最高 6 倍），也支持 Mac 触摸板双指张合缩放和双指滑动查看；点击图片、右上角关闭按钮或按 `Esc` 退出预览。
- 开启“移出隐藏”后，鼠标移出时答题页缩成右上锚定的 20×20 无字小圆球，颜色跟随“题目与选项颜色”；小球可跨显示器拖动但不会超出屏幕可见范围，只有鼠标移到小圆球上才恢复原答题页尺寸和位置。
- “一题一判”会在选项后显示对错、答案、解析和下一题按钮；“整卷后判”会显示得分及可滚动的逐题结算页。结算页中对题的勾、答案和解析为绿色，错题的叉、答案和解析为红色，右侧题号可点击跳转。
- 每套选定范围独立记录上次得分和最高得分，每题 1 分；管理页同时显示言语、常识、数量、判断和资料五个模块的首次作答正确率，重做不会改写该统计。
- 整卷判定模式会按题库和本次选题范围保存断点、已选答案和已用时间，下次自动从上次停下的题继续；勾选“从头开始做”会同时清除本卷断点并将计时清零。
- 整卷进入答题页即开始计时；超过设定时限后显示红色“已超时”，但仍可继续答题。勾选“缩成小圆球时暂停计时”后，缩球会暂停，恢复答题页时继续。
- 错题记录永久保留，之后答对也不会自动移除；只能在管理页选中后点击“删除错题记录”。
- `⌘⌥Q`：全局显示或隐藏答题页。
- `⌘⌥L`：锁定/解除当前答题页状态。锁定展开状态后鼠标移出也不缩球；锁定小圆球状态后鼠标移入也不恢复。
- 答题记录保存在 `~/Library/Application Support/QuickQuiz/`。

## 自检

```bash
dist/轻刷题.app/Contents/MacOS/QuickQuiz --self-test
```

该命令用于兼容性测试内置的旧双 PDF 题库。

也可以测试单个合订 PDF：

```bash
dist/轻刷题.app/Contents/MacOS/QuickQuiz --self-test-single "/路径/答案解析.pdf"
```

## 即将开发

### 1. Windows 适配

- 提供 Windows 桌面版本和可直接运行的安装包。
- 保留悬浮答题、透明背景、快捷键、缩球和本地持久化等核心体验。

### 2. 多题库管理

- 支持同时导入、命名、切换和删除多套题库。
- 每个题库独立保存错题、成绩、模块正确率、断点和计时。
- 增加题库列表、题库检索、导入状态和备份/恢复能力。
